# Мосэнергосбыт for Home Assistant

Интеграция Home Assistant для управления счётчиками и данными из приложения **Мосэнергосбыт+**.

## Установка через HACS

1. Откройте **HACS → Integrations**.
2. Нажмите **⋮ → Custom repositories**.
3. Добавьте URL: `https://github.com/Pshatsillo/mosenergosbyt`, категория — **Integration**.
4. Найдите **Domiland** в HACS → **Download**.
5. Перезапустите Home Assistant.
